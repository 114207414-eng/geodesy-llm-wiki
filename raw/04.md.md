# 大地測量學 Ch6 重點整理：橢球面到投影平面（地圖投影）

整理自《大地測量學》第六章講義

## 6.1 地圖投影的概念

- **目的**：橢球面上計算複雜，所以把大地坐標 (φ, λ) 歸算到平面直角坐標 (x, y)。
- **投影方程**：x = F₁(φ, λ)，y = F₂(φ, λ)。
- **變形原因**：橢球面不可展，投影必有變形。
- **長度比** m = ds/dS，隨位置與方向而變。
- **主方向**：長度比最大與最小的兩個互相垂直方向，其長度比記為 a、b。
- **變形橢圓**：橢球面上的單位微分圓，投影後變成以 a、b 為半軸的橢圓。
- **各種變形**：
  - 長度變形 ν = m − 1，且 m² = a²cos²α + b²sin²α
  - 方向變形：sin(α − α′) = (a − b)/(a + b) · sin(α + α′)
  - 最大角度變形：Δu = 2ω，sin(ω/2) = (a − b)/(a + b)
  - 面積比 P = ab

### 投影分類

**按變形性質**

- **等角（正形）**：a = b，長度比與方向無關，微小圓形仍相似。
- **等積**：ab = 1。
- **任意**：以上皆非。其中 a = 1 或 b = 1 者稱為等距離投影。

**按經緯網形狀**

- **方位投影**：切平面，緯線為同心圓。
- **圓錐投影**：緯線為同心圓，經線為半徑。
- **圓柱投影**：經緯線為互相垂直的兩組平行線。

## 6.2 高斯投影概述

- **測量對投影的要求**：等角、長度與面積變形小、可分帶。
- **高斯投影**又稱橫軸橢圓柱等角投影（高斯－克呂格投影）。橢圓柱橫套地球，與中央子午線相切。
- **分帶**：6° 帶自 0° 起向東編號，3° 帶以 6° 帶的中央子午線與分界線為中央子午線。
- **坐標系**：中央子午線投影為 y 軸（縱），赤道為 x 軸（橫），並加 500,000 m 的偽東並冠以帶號。
- **特點**：
  - 中央子午線無變形
  - 無角度變形
  - 離中央子午線愈遠，變形愈大
- **歸算內容**：
  1. 高斯坐標正反算
  2. 方位角歸算：A → α = A − γ + δ，其中 γ 為子午線收斂角，δ 為方向改正（曲率改正）
  3. 各方向改正
  4. 距離改正：s = S + Δs
  5. 鄰帶換算

## 6.3 正形投影一般條件

- **等量緯度**：q = ∫(M/(N cosφ))dφ，使 dq 與 dl 成為獨立變量。
- **長度比**：m² = (dx² + dy²)/(r²(dq² + dl²))，其中 r = N cosφ。
- **令** E = (∂x/∂q)² + (∂y/∂q)²，F = (∂x/∂q)(∂x/∂l) + (∂y/∂q)(∂y/∂l)，G = (∂x/∂l)² + (∂y/∂l)²。
- **正形條件**：m 與方位角無關，須 F = 0 且 E = G，推得**柯西－黎曼條件**：
  - ∂x/∂q = ∂y/∂l
  - ∂x/∂l = −∂y/∂q
- 此時 m² = E/r² = G/r²。
- **幾何意義**：由此可導出子午線收斂角 γ 與長度比 m 的計算式。

## 6.4 高斯投影坐標正反算

### 高斯投影的三個條件

1. 中央子午線投影為直線。
2. 中央子午線長度不變。
3. 正形條件。

### 正算（φ, λ → x, y）

- 將 x、y 展開為經差 l 的冪級數。x 為 l 的奇函數，y 為 l 的偶函數。
- 係數由柯西－黎曼條件遞推，並以 m₀ = Y（赤道至該點的子午線弧長）為起點。
- 結果：
  - y = Y + (N/2)·sinφcosφ·l² + (N/24)·sinφcos³φ(5 − t² + 9η² + 4η⁴)·l⁴ + …
  - x = N cosφ·l + (N/6)cos³φ(1 − t² + η²)·l³ + (N/120)cos⁵φ(5 − 18t² + t⁴ + …)·l⁵ + …
  - 其中 t = tanφ，η² = e′²cos²φ，要求精度 0.001 m 時取到 l⁶ 項。

### 反算（x, y → φ, λ）

- 將 φ、l 展開為 x 的冪級數。φ 為偶函數，l 為奇函數。
- 起點是 n₀ = φ\_f，也就是「底點緯度」，即 y = Y 時子午線弧長所對應的緯度。
- 流程：由 y 求 φ\_f，再求 (φ\_f − φ) 與 l，最後 φ = φ\_f − (φ\_f − φ)，λ = λ₀ + l。

## 6.5 平面子午線收斂角 γ

- **定義**：子午線投影的切線與坐標北（縱軸）之間的夾角。
- **由 (φ, λ)**：γ = l·sinφ + (l³/3)sinφcos²φ(1 + 3η² + 2η⁴) + (l⁵/15)sinφcos⁴φ(2 − t²) + …
- **性質**：
  - γ 為 l 的奇函數，l 愈大 γ 愈大
  - 中央子午線以東為正，以西為負
  - l 不變時，γ 隨緯度增加而增大
- **由 (x, y)**：γ ≈ (x/N\_f)·t\_f − (x³/(3N\_f³))·t\_f(1 + t\_f² − η\_f²) + …

## 6.6 UTM 投影

- **定義**：Universal Transverse Mercator，即 m₀ = 0.9996 的高斯投影，由美國軍方於 1938 年提出，1945 年採用。
- **坐標關係**：x、y 比高斯投影坐標多乘 0.9996。
- **長度變形**：中央子午線 m = 0.9996（變形 −0.0004）。兩條割線在赤道約離中央子午線 180 km 處，無變形。割線以內為負變形，以外為正變形，3° 處最大約 +0.001。
- **分帶**：全球 60 帶，每帶 6°，自 180°W–174°W 為第 1 帶向東編號，適用南緯 80° 至北緯 80°。
- **偽坐標**：
  - 北半球：x = x\_計 + 500,000（東）或 500,000 − x\_計（西），y = y\_計
  - 南半球：同上，但 y = 10,000,000 − y\_計
- **中央子午線經度**：
  - 帶號 < 30（西經）：λ₀ = 6(30 − n) + 3（例：第 25 帶為 33°W）
  - 帶號 > 30（東經）：λ₀ = 6(n − 30) + 3（例：第 51 帶為 123°E）
- **中國範圍**：第 43 至 53 帶。

## 台灣的 2°、3°、6° 分帶

| 分帶 | 用途 | 中央子午線尺度比 | 西移 | 備註 |
| --- | --- | --- | --- | --- |
| TM2（2°） | 地籍、五千分一以上大比例尺 | 0.9999 | 250,000 m | 台灣為 121°E，尺度誤差約 1/10,000～1/20,000 |
| TM3（3°） | 五千分一（不含）至二萬分一 | 1 | 350,000 m | 121°E，尺度誤差約 1/3000 |
| UTM（6°） | 小於二萬五千分一 | 0.9996 | 500,000 m | 本島第 51 帶（123°E），澎湖第 50 帶（117°E），尺度誤差約 1/1500～1/1000 |

- **分三種的原因**：讓各比例尺地圖的精度不被投影誤差損害，尤其地籍涉及人民權利與面積。
- **補充**：上課簡報提到 TWD97 採 TM2、中央子午線 121°E（澎湖、金門、馬祖為 119°E）、尺度比 0.9999、西移 250,000 m，與此處 TM2 一致。
