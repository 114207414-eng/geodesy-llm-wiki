## 一、球諧函數與引力位展開

依據 `raw/05.md.md`（p.51–69）：
地球內部質量分布無法直接測得，因此透過泰勒級數與勒讓德多項式將外部引力位展開為多極球諧函數級數：
$$V = \sum_{n=0}^{\infty} V_n = \sum_{n=0}^{\infty} \frac{1}{r^{n+1}}\left[ A_n P_n(\cos\theta) + \sum_{K=1}^{n} (A_n^K \cos K\lambda + B_n^K \sin K\lambda) P_n^K(\cos\theta) \right]$$
其中 $r$ 為向徑，$\theta$ 為極距（餘緯，$\theta = 90^\circ - \phi$），$\lambda$ 為經度，$P_n(\cos\theta)$ 為勒讓德多項式，$P_n^K(\cos\theta)$ 為勒讓德伴隨函數。

### 1. 各階引力位的物理本質
- **零階項 ($v_0$)**：
  $$v_0 = \frac{fM}{r}$$
  代表將地球全部質量 $M$ 集中於地心時的質點引力位，占整體引力場的 99.9% 以上。
- **一階項 ($v_1$)**：
  $$v_1 = \frac{f}{r^3}(x\int x_m dm + y\int y_m dm + z\int z_m dm)$$
  物理上代表坐標原點與地球質心的空間偏差。現代地心坐標系（如 WGS84、ITRF）規定原點精確位於質心，故**強制令 $v_1 = 0$**。
- **二階項 ($v_2$)**：
  反映地球自轉產生的赤道隆起與兩極扁平特徵，即最關鍵的動力學形狀因子 **$J_2$ 項**。
- **三階項 ($v_3$)**：
  反映地球南北半球不對稱的「梨形」幾何起伏。

### 2. 三大類球諧函數圖案特徵
依據 `raw/05.md.md`（p.62–64）：
1. **帶球函數 (Zonal Harmonics, $K=0$)**：
   - 與經度 $\lambda$ 無關，節線為平行緯線，像斑馬線橫切地球。用於模擬地球整體扁率（$J_2$）及南北半球不對稱（$J_3$）。
2. **扇球函數 (Sectorial Harmonics, $K=n$)**：
   - 節線全部穿過南北兩極，像切西瓜或橘子瓣，沿經線縱向交替分布。
3. **田球函數 (Tesseral Harmonics, $n \neq K \neq 0$)**：
   - 經向與緯向同時具備節線，呈現如棋盤或田字格的區塊交替。用於精細捕捉局部區域（如高山、海溝）的重力起伏。

### 3. 斯托克斯常數 (Stokes' Constants)
- 級數中的係數 $A_n, A_n^K, B_n^K$ 稱為斯托克斯常數，直接對應地球內部轉動慣量與各階質量矩。
- 人造衛星透過精密軌道攝動觀測反求這數百個常數，即可精確繪製全球重力場圖。

## 二、正常重力位與擾動位

依據 `raw/05.md.md`（p.70–88, 115–123）：
### 1. 正常重力位定義的三大簡化假設
為獲得數學上光滑、可精確計算的理想參考重力場，人為設定正常重力位 $U$ 需滿足以下三項約束：
1. **原點置於地心**：強制一階項全部為零（$A_1 = A_1^1 = B_1^1 = 0$）。
2. **坐標軸對齊主慣性軸**：消除非對稱翹曲（$A_2^1 = B_2^1 = B_2^2 = 0$）。
3. **旋轉軸對稱（繞極軸東西完全對稱）**：赤道轉動慣量 $A = B$，使所有與經度 $\lambda$ 相關的項全部為零。

### 2. 正常重力位數學公式
在保留至二階項後，正常重力位 $U$ 簡化為僅與距離 $r$ 和極距 $\theta$ 相關之封閉函數（式 3-99、3-102）：
$$U = \frac{fM}{r} \left[ 1 + \frac{\mu}{3}(1 - 3\cos^2\theta) + \frac{q}{2}\sin^2\theta \right]$$
其中：
- $q = \frac{\omega^2 a}{g_e} \approx \frac{1}{288.9} \approx \frac{1}{289}$：赤道離心力與重力之比。
- $\mu = \frac{3K}{2a^2} = \frac{3(C-A)}{2Ma^2}$：地球動力學形狀參數（$C, A$ 分別為繞極軸與赤道軸之轉動慣量）。

### 3. 擾動位 $T$ (Disturbing Potential)
真實重力位 $W$ 與理論正常重力位 $U$ 之差稱為**擾動位 $T$**：
$$W = U + T$$
- 正常橢球已吸收真實地球約 **99.9%** 的質量與幾何形狀效應。
- 整個物理大地測量學的核心任務，實質上就是求解此一微小的擾動位 $T$。

## 三、水準橢球與克萊羅定理

依據 `raw/05.md.md`（p.84–106）：
### 1. 水準橢球面方程
令正常重力位為一固定等位面常數 $U_0$，解得其邊界面向徑幾何方程（式 3-106）：
$$r = a\left[ 1 - (\mu + \frac{q}{2})\cos^2\theta \right]$$
對比旋轉橢圓幾何一階方程 $r \approx a(1 - \alpha\cos^2\theta)$，可知：
$$\alpha = \mu + \frac{q}{2}$$
- **結論**：一個處於流體靜力平衡且均勻旋轉的星體，其等位水準面幾何形狀**嚴格為旋轉橢球體**（水準橢球）。幾何扁率 $\alpha$ 物理上嚴格等於形狀因子 $\mu$ 與離心力比值半數 $q/2$ 之和。

### 2. 克萊羅定理 (Clairaut's Theorem)
由正常重力定義 $\gamma = -\frac{dU}{dn} \approx -\frac{dU}{dr}$，導出赤道正常重力 $\gamma_e$ 與極點正常重力 $\gamma_p$：
- $\gamma_e = \frac{fM}{a^2}(1 + \alpha - \frac{3}{2}q)$
- $\gamma_p = \frac{fM}{a^2}(1 + q)$
- 定義重力扁率 $\beta = \frac{\gamma_p - \gamma_e}{\gamma_e} = \frac{5}{2}q - \alpha$。
- **克萊羅定理經典形式**（式 3-111、3-123）：
  $$\alpha + \beta = \frac{5}{2}q$$
- **物理意義**：將不可深入量測的幾何扁率 $\alpha$ 與地面可觀測的重力變化率 $\beta$ 透過動力學參數 $q$ 建立嚴密關聯。只要在地表觀測重力差值即可反求地球橢球的幾何扁率。

### 3. 正常重力展開公式與中緯度修正
考慮四階項（$\alpha^2$ 級）的高精度正常重力展開式（式 3-113）：
$$\gamma_0 = \gamma_e \left( 1 + \beta\sin^2\phi - \beta_1\sin^2 2\phi \right)$$
其中 $\beta_1 = \frac{1}{8}\alpha^2 + \frac{1}{4}\alpha\beta$。
- **$\sin^2 2\phi$ 項的物理意義**：一階公式僅呈現由赤道向兩極單調遞增，但在中緯度 $\phi = 45^\circ$ 處二次效應最大（$\sin^2 90^\circ = 1$）。此項為負號，用以修正中緯度幾何曲率與引力場所產生的二階偏差。

### 4. 索米里安納公式 (Somigliana Equation)
現代 GPS 與 WGS-84 採用的嚴密無截斷誤差閉合解（式 3-118、3-119）：
$$\gamma = \gamma_e \frac{1 + K\sin^2\phi}{\sqrt{1 - e^2\sin^2\phi}}$$
其中索米里安納常數 $K = \frac{b\gamma_p - a\gamma_e}{a\gamma_e}$。
- **WGS-84 數值形式**：
  $$\gamma = 978.03267714 \times \frac{1 + 0.00193185138639\sin^2\phi}{\sqrt{1 - 0.00669437999013\sin^2\phi}}\text{ Gal}$$

## 四、正常重力的高程修正（自由空間修正）

依據 `raw/05.md.md`（p.107）：
地面高度 $h$（以公尺為單位）處的正常重力 $\gamma$ 隨高程增加而衰減。透過萬有引力展開泰勒級數：
$$\Delta_1 g = \gamma_0 - \gamma \approx \frac{2\gamma_0}{R}h - \frac{3\gamma_0}{R^2}h^2 \approx 0.3086 h\text{ (mGal)}$$
- **工程法則**：**地面大約每升高 3 公尺，正常重力值約減少 1 mGal**。
- 自由空間高程修正公式：
  $$\gamma = \left( \gamma_0 - 0.3086 h \right) \times 10^{-3}\text{ Gal}$$

## 五、正常重力場的四個獨立基本常數

依據 `raw/05.md.md`（p.108–123）：
依據**斯托克斯定理**，旋轉橢球正常重力場完全由 **4 個相互獨立的基本常數**決定：
1. **$a$（長半軸）**：決定橢球幾何大小。
2. **$J_2$（二階帶諧係數）**：透過人造衛星軌道節點攝動精確測定，決定地球動力學扁率與質量分佈。
3. **$fM$（地心引力常數）**：決定地球總質量與主引力強度。
4. **$\omega$（地球自轉角速度）**：決定自轉離心力場大小。

### WGS-84 定義參數值（式 3-131）
- $a = 6,378,137\text{ m}$
- $J_2 = 1082.62998905 \times 10^{-6}$
- $fM = 3986005 \times 10^8\text{ m}^3\text{s}^{-2} = 398600.5\text{ km}^3/\text{s}^2$
- $\omega = 7292115 \times 10^{-11}\text{ rad/s}$
- **導出量**：
  - 幾何扁率 $\alpha = 1 / 298.257223563$
  - 赤道重力 $\gamma_e = 9.7803267714\text{ m/s}^2$
  - 極點重力 $\gamma_p = 9.8321863685\text{ m/s}^2$
  - 重力扁率 $\beta = 0.00530244012894$
